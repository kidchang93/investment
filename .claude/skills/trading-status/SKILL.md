# trading-status: 지금 시스템이 어떻게 돌고 있나

**읽기만 한다.** 환경을 세우지도(그건 `morning.sh`), 주문을 내지도 않는다.

## 왜 이 스킬이 있나 (2026-08-14)

하루에 세 번 "지금 뭐가 살아 있지?"를 손으로 확인했고, 그날 이런 것들이 드러났다:

- 아침에 Docker·Postgres·백엔드가 **전부 죽어 있었다** (8/6·8/7·8/10도 그랬다)
- launchd 자동화가 **8일째 조용히 실패**하고 있었다 — 아무도 몰랐다
- PID 파일이 살아 있는 데몬을 "멈췄다"고 말했다

셋 다 **물어보지 않으면 모르는 것**이었다. 그래서 한 명령으로 묶었다.

## 1. 실행

```bash
zsh scripts/status.sh
```

이 스크립트가 다섯 가지를 한 화면에 찍는다:

| 구역 | 무엇을 보나 |
|---|---|
| 돌고 있는 것 | 데몬 · 백엔드 · Docker · Postgres |
| 주문이 어디로 나가나 | `APP_ENV` · 게이트 · 앱키–서버 짝 명시 여부 |
| 계좌와 3층 | 층별 원가·평가·손익·비중, **장부와 증권사 잔고 대조** |
| 오늘 자동으로 한 일 | 하트비트 (KST 기준) |
| 다음 자동 실행 | 지금 시각·요일로 계산 |

`layerReport.ts`가 장부·잔고 불일치를 만나면 **exit 1**을 낸다. 그건 실패가 아니라
**이 검사의 목적**이다 — 그 사실을 사람에게 알리는 것.

## 2. 무엇을 짚어야 하나

출력을 그대로 옮기지 말고 **이상한 것을 골라 말한다.** 정상이면 정상이라고 짧게 적는다.

### 반드시 짚을 것

- **○(죽음) 표시가 하나라도 있으면** — 무엇이 죽었고 어떻게 살리는지. 데몬이 멈춰 있으면
  그동안의 자동 실행이 통째로 빠졌다는 뜻이다
- **`APP_ENV=prod`이면** — 주문이 실계좌로 나간다. 이건 크게 알린다
- **`KIS_<id>_SERVER`가 없으면** — 앱키가 어느 서버용인지 **추정**으로 돈다(`CLAUDE.md` 7-1)
- **장부와 잔고가 어긋나면** — 그 위의 층별 숫자를 **믿으면 안 된다**. 손으로 낸 주문이
  있었는지, 빠진 매매가 있는지 확인해야 한다
- **평일 08:30 이후인데 하트비트가 비어 있으면** — 데몬이 멈춰 있었다는 뜻이다
- **비중이 목표에서 크게 벗어나 있으면** — 얼마나, 어느 방향인지. 복원은
  `npx tsx src/scripts/rebalance.ts`(계획) → `--execute`(집행)

### 자주 오해하는 것

- **`cashBalance`(D+0)는 오늘 산 것이 안 빠진 값이다.** 쓸 수 있는 돈은 D+2다.
  D+0으로 비중을 내면 자산이 부풀어 현금 비중이 실제의 두 배로 보인다
- **손익이 한 종목에서 나오는지 본다.** 2026-08-14에 평가손익의 98%가 KODEX 200
  하나였다. 층 합계만 보면 분산이 작동하는 것처럼 읽힌다
- **`survived`나 "넘었다"는 비용을 넘었다는 뜻이 아니다.** 정보가 있다는 것과 돈이
  된다는 것은 다른 질문이다

## 3. 상태에 따라 이어서 제안할 것

| 보이는 것 | 제안 |
|---|---|
| 데몬 멈춤 | `zsh scripts/daemon.sh start` |
| 백엔드·DB 죽음 | `zsh scripts/morning.sh` |
| 비중 이탈 | `npx tsx src/scripts/rebalance.ts`로 계획부터 본다 |
| 장부·잔고 불일치 | 오늘 주문 기록을 열어 손으로 낸 것이 있는지 본다 |
| 단기·유망주 층이 0원 | 목표(연 15~20%)까지 무엇이 비어 있는지 산수로 짚는다 |

## 4. 하지 말 것

- **고치지 마라.** 이 스킬은 진단이다. 사용자가 시키면 그때 고친다
- **주문을 내지 마라.** 상태 확인에 매매가 따라올 이유가 없다
- 출력을 통째로 복사하지 마라 — 사용자는 이미 볼 수 있다. **해석을 준다**
- 정상인 항목을 길게 설명하지 마라. **이상한 것에 지면을 쓴다**

## 관련

- `scripts/daemon.sh` — 상주 스케줄러 (start/status/stop)
- `scripts/morning.sh` — 환경을 **세운다** (이 스킬은 보기만 한다)
- `scripts/rebalance.ts` — 비중 복원 (멱등 키라 재시도해도 안전)
- `backend/src/scripts/layerReport.ts` — 3층 성과 단독 실행
- `docs/TRADING_API.md` — 주문 경로와 차단 사유
